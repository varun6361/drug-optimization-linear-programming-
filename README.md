# 🚀 Drug Optimization using Linear Programming

## 📌 Project Overview

This project solves a business problem using **Linear Programming** to maximize profit under resource constraints. The model determines the optimal number of drug units to produce.

---

## 🎯 Objective

Maximize total profit while satisfying resource limitations.

---

## ⚙️ Technologies Used

* Python
* PuLP (Linear Programming)
* NumPy

---

## 🧠 Problem Description

We consider two drugs:

* Drug A
* Drug B

Each drug requires resources and generates profit. The goal is to find the optimal production quantities.

---

## 📊 Mathematical Model

### Objective Function:

Maximize:

```
20x + 30y
```

### Constraints:

```
2x + y ≤ 100  
x + 3y ≤ 90  
x ≥ 0, y ≥ 0
```

---

## 📈 Results

* Optimal Drug A: 30 units
* Optimal Drug B: 20 units
* Maximum Profit: ₹1200
